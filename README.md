Projeto desenvolvido durante o Intensivão Java Spring Boot (DevSuperior – Prof. Nélio Alves), com o objetivo de praticar a construção de uma API REST utilizando Spring Boot.
Objetivo do Projeto

--------x-------

Criar uma API backend aplicando conceitos de:

Arquitetura em camadas.

Programação Orientada a Objetos.

Persistência de dados com JPA.

Criação de endpoints REST

Boas práticas no desenvolvimento backend.

------- x ---------

Tecnologias Utilizadas

Java.

Spring Boot.

Spring Data JPA.

Hibernate.

Banco de dados H2.

Maven.

--------x--------

Funcionalidades:

Cadastro de jogos.

Atualização de dados.

Movimentação de ranking.

Tratamento de exceções.

--------x---------

O projeto segue arquitetura em camadas:

Controller.

Service.

Repository.

Entities.

-----------------x---------------

Durante o desenvolvimento deste projeto, pratiquei:

Construção de APIs REST.

Injeção de dependência.

Mapeamento objeto-relacional (ORM).

Padrão DTO.

Tratamento de exceções personalizadas.

Versionamento com Git.
